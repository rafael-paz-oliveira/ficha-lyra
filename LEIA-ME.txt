FICHA DE PERSONAGEM - FABULA ULTIMA (app web)
=============================================

Esta página é genérica: não contém dados de nenhum personagem.
Cada pessoa guarda a própria ficha em um repositório PRIVADO no GitHub.

Como usar
  1. Abra a página (no celular ou tablet, "Adicionar à tela inicial").
  2. Preencha a ficha. Tudo é salvo sozinho no próprio aparelho.
  3. Para levar a ficha entre aparelhos: menu (botão redondo no canto superior
     direito) > Sincronização e backup > Sincronia pelo GitHub.
       - Crie um repositório PRIVADO só para a ficha.
       - Gere um token (fine-grained) com acesso só a esse repositório e
         permissão Contents: Read and write.
       - Informe repositório (dono/nome), token e nome do arquivo.
     Com a sincronia automática ligada, vale a ficha editada por último.

O token fica apenas no aparelho. Nunca publique o token nem a ficha em
repositório público.
